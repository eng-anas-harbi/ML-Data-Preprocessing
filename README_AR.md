# تجهيز البيانات لموديلات تعلم الآلة

هالمشروع يوضح **طريقة تجهيز البيانات** قبل ما نستخدم أي موديل تعلم آلة.  
فيه خطوات زي:

- التعامل مع القيم الفارغة
- ترميز البيانات اللي مو رقمية
- تقسيم البيانات لمجموعتين: تدريب واختبار
- توحيد المقاييس للأرقام الكبيرة

---

## قاعدة البيانات

الملف `Data.csv` فيه:

- Country (فرنسا، إسبانيا، ألمانيا)
- Age
- Salary
- Purchased (Yes / No)

---

## طريقة الاستخدام

1.حط ملف البيانات 'Data.csv' في نفس الملف مع اي ملف workflow
2. شغل الملف بالبايثون
3. بعد ما يشتغل، بيطلع لك:
   - `x_train`, `x_test` : البيانات جاهزة للتدريب والاختبار
   - `y_train`, `y_test` : القيم المستهدفة بعد الترميز

---

## ملاحظات

- بعض الخطوات مثل التوحيد (Scaling) ممكن ما تحتاجها لبعض الموديلات، زي Decision Trees أو Random Forest.  
- كل خطوة مشروحة بالكومنتات داخل الكود.
